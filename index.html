03 · INNOVATION

三大技术创新：我们「新」在哪里

不是工具堆叠，是让 AI 在真实攻防场景中能自主、能通用、能可控的工程化创新。

🔀

创新一 · 按复杂度自动选型的三层编排

现有方案「单 Agent 一条道走到黑」或固定编排。我们让编排器按任务复杂度在 Deep / Plan-Execute / Supervisor 间自动切换，兼顾效率与成功率。

  • 基于 cloudwego/eino 编排框架
  • 模型输入估算 telemetry，成本可控
  • 模型韧性：通道失败自动降级
🧩

创新二 · 90 工具 × 16 Agent 全链路通用对抗

把碎片化安全工具统一为 YAML 配方 + MCP 协议，Agent 可编排调用、上下文共享，写一个 YAML 即可接入新工具。

  • 角色-工具映射，越权调用被拒
  • 事实黑板跨 Agent 传递上下文
  • 审计 Agent 独立复核执行证据
🔐

创新三 · HITL 审批 × 全链路审计

自主决策 ≠ 放任自流。危险操作进人工审批队列（倒计时 + 拒绝机制），审计 Agent 复核，全链路证据可回放。

  • c2_hitl_bridge：C2 与审批流桥接
  • 工具白名单 + 权限校验
  • 审计脱敏：敏感信息不入日志

05 · DOWNLOAD

下载部署：三步在本机跑起来

Windows 电脑直接部署 —— 安装向导选目录安装，无需 Docker、无需云端算力、无需配置环境。

1

选择平台

顶部按平台下载：Windows 安装版（推荐，32 MB）或绿色版（158.8 MB）；Linux / macOS 为单文件可执行版（chmod +x 后运行）

2

启动

Windows：跟随安装向导（自动创建桌面快捷方式），SmartScreen 提示点 更多信息 → 仍要运行；Linux/macOS：chmod +x secautomind-ai-linux-amd64 && ./secautomind-ai-linux-amd64

3

登录使用

启动后浏览器访问 http://127.0.0.1:8080；初始账号 admin，密码见安装目录 data/admin_initial_password.txt（仅首次生成）

⚠️ SmartScreen 说明：程序为自编译未签名版本，首次运行 Windows 会拦截，属正常现象（非病毒）。建议下载后核对 SHA-256 校验值（见 GitHub Releases）。
