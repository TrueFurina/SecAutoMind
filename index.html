Download & Install

下载部署：三步跑起来

Windows 电脑直接部署，无需 Docker、无需云端算力、无需配置环境

1

下载可执行文件

点击上方 立即下载 获取 secautomind-ai.exe（约 144 MB，Windows 64 位）。 也可从 GitHub Releases 下载历史版本与校验文件。

2

双击启动（首次需放行 SmartScreen）

Windows 可能提示「已保护你的电脑 / 未知发布者」——点击 更多信息 → 仍要运行。 首次启动会自动生成管理员初始密码（仅显示一次，请立即保存并登录后修改）。

3

打开浏览器使用

启动后访问 http://127.0.0.1:8080，用生成的账号密码登录， 在「设置」中配置 AI 通道（可接入国内备案大模型，如通义千问），即可开始攻防推演。

⚠️ SmartScreen 提示说明：程序为独立开发者自编译签名前的版本，首次运行 Windows 会拦截，属正常现象（非病毒）。 建议核对 SHA-256 校验值后再运行，校验文件见 Releases。
